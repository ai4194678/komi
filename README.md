# Медиакоми — «Угадай цену квартиры»

Мини-игра на основе реальных объявлений о продаже квартир в г. Инта (Республика Коми) с Авито. Игроку показывают фотографии квартиры, он оценивает её цену бегунком и узнаёт реальную цену, разницу и ссылку на объявление. За 10 раундов набираются баллы, в конце — типаж игрока: «Жадный студент», «Адекватный квартирант» или «Транжира».

## Запуск локально

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `mediakomi`).
2. Загрузите туда файлы `index.html` и `data.js`:
   ```bash
   git init
   git add index.html data.js README.md
   git commit -m "Медиакоми: игра-угадайка цен на квартиры"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mediakomi.git
   git push -u origin main
   ```
3. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через минуту игра будет доступна по адресу
   `https://<ваш-логин>.github.io/mediakomi/`

Никакой сборки и зависимостей не нужно — два статичных файла.

## Балльная система

- За каждый раунд: `балл = 100 × max(0, 1 − |оценка − реальная цена| / реальная цена)`, округляется до целого.
- Точное попадание — 100 баллов; промах в 2 раза и больше — 0.
- Максимум за игру — 1000 баллов (10 раундов × 100).
- Типаж на финале считается по средней относительной ошибке оценок:
  - ниже реальных более чем на 10% — **Жадный студент**;
  - выше реальных более чем на 10% — **Транжира**;
  - в пределах ±10% — **Адекватный квартирант**.

## Данные

`data.js` сгенерирован из таблицы объявлений (только лоты с фотографиями — 36 активных карточек). При каждом запуске игры случайные 10 из них перемешиваются.
